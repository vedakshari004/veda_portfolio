Overview
This is a personal portfolio Android application built using Jetpack Compose and Material3, showcasing the profile, projects, skills, certifications, education, and participations of Yeruva Vedakshari. It also includes a theme toggle feature and external links to email and LinkedIn.
Features
 Profile with image, name, and brief description
 Sections for Skills, Education, Projects, Certifications, and Participations
 Light/Dark theme toggle with in-app switch
 One-click email integration
 LinkedIn profile redirect
 Pastel color palette for a soft visual experience
 Responsive design with scrollable layouts
Technologies Used
 Kotlin
 Jetpack Compose
 Material3
 AppCompatDelegate
 Intent-based navigation
 XML + Compose hybrid UI
How to Install
 Download the APK from the release section.
 Enable installation from unknown sources on your Android device.
 Tap the APK file to install and open it.
